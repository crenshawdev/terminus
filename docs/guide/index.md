# Terminus

Terminus is a local archive of your Claude Code sessions, for a developer who comes back to the same projects and wants what was said and decided in them to still be there. It keeps every session whole and offers it back to Claude, and you can search it yourself.

This guide follows the work: install it, see what Claude gets, read the archive yourself, and decide what to keep. The archive has its own section because what Terminus stores and what it can find decide what you can rely on it for. The configuration and command references are there when you need them.

If you're new to Terminus, start with [installation](getting-started/install.md). If it's already installed, start with [what Claude gets](working/what-claude-gets.md).
