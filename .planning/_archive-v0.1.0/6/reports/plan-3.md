[deviation] Task 2's Action puts the bound on `Filters` / `Filters::push_onto` and states "Default stays `None` so every existing caller is untouched". Both cannot hold: `crates/verbatim/src/cmd/mcp/tools.rs:332` builds `Filters` with an exhaustive struct literal, so any field added to `Filters` fails to compile there - and that file is in no plan's `files:` lease. The bound is therefore a field of `Request`, which is only ever constructed through `Request::new`, so the "every existing caller untouched" half of the Action holds exactly. The `Verify:` is met unchanged.
[deviation] Task 3's Action asks replay to apply "the recorded dropped-turn set" when "the record says the compacted pool was in force". The `decisions` TABLE carries neither field: PLAN-1's drain inserts eleven columns and `compacted`/`dropped` are not among them, and `store/schema.rs` is outside this plan's lease. Replay therefore scores every decision through the ordinary ranked window, which is the same posture the plan's own Notes take on suppression ("re-deriving would attribute state noise to the rule change"). Stated in the module header. Nothing in the task's `Verify:`, the plan's `Must be true when done` or AC4 asks for the compacted pool.
[deviation] Task 4's Action asks the test to "assert no `-wal`/`-shm` growth" alongside the byte hash. A first read-only open of a WAL database necessarily materializes `verbatim.db-shm` (32 KiB) and an empty `verbatim.db-wal` - SQLite's shared-memory index, which every reader needs and which a read-only connection cannot unlink on close - so that assertion is unmeetable as written, and is unmeetable for `search`, `show`, `sessions` and the MCP server too. Measured directly against a real store. What is asserted instead: `verbatim.db` is byte-identical, the WAL holds zero bytes (no frame was written), and a second replay grows neither sidecar. The plan's `Must be true when done` ("leaves the store file byte-identical") holds exactly; the fact is written into the test and into the `replay` section of `docs/json-shapes.md`.
