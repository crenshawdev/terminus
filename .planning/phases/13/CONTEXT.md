## Durable decisions

- D-12 (decisions table, #40): `compacted` is a nullable `INTEGER`, where null means the decision was drained before the column existed and its value is unknown. `dropped` is a `TEXT` JSON document, like the other list-shaped columns. `NOT NULL DEFAULT 0` was rejected because it would record every earlier decision as ordinary for good. Evidence: `crates/terminus-core/src/store/schema.rs:130-146`, `crates/terminus-core/src/store/schema.rs:271-290`, `crates/terminus-core/src/feedback/mod.rs:214-216`.
- D-14 (stats output, #40): `terminus stats` gains additive `--json` keys and human lines that count compacted decisions apart from ordinary ones. `docs/json-shapes.md`, `DATA_COMMANDS` in `tests/cli.rs` and `docs/commands.md` change in the same change. No shipped key is renamed, and once shipped these keys are not renamed later. Evidence: `crates/terminus/src/cmd/stats.rs:55-110`, `crates/terminus/tests/cli.rs:1008-1022`, `docs/json-shapes.md:233-256`, `docs/commands.md:158-160`, phase 12 D-01.
- D-19 (boundaries, #17): A `system`/`compact_boundary` record with no `uuid` or no `timestamp` does not become a turn. Record classification, `turn_seq` and `turns.id` stay as they are. Making it a turn with a null `uuid` and `ts` was rejected, because the reindex would shift turn ids in any session holding one, and archived `labels`, decision JSON and state files would point at the neighbouring turn. None of the 2,062 transcripts under `~/.claude/projects` holds such a record today (measured 2026-10-15), so this is a guard. Evidence: `crates/terminus-core/src/parse/record.rs:159-177`, `crates/terminus-core/src/parse/mod.rs:61-77`, `crates/terminus-core/src/store/schema.rs:28-48,218-231`, `crates/terminus-core/src/inject/decision.rs:136-152`.
- D-20 (boundaries, #17): Boundary rows move to a new derived table keyed by `(session_key, stream_offset)`, replacing `compaction_boundaries`. `CREATE_SQL`'s `IF NOT EXISTS` creates it on both reindex paths, including the one that keeps evicted sessions and never drops a derived table. Re-keying `compaction_boundaries` in place was rejected: its `turn_id INTEGER PRIMARY KEY` would hand a null `turn_id` the next turn's id, and the preserving reindex path would never reach the new shape. Ingest and reindex both gain a path that writes boundary rows for records that are not turns, and `observe/mechanical.rs`, `reindex.rs::clear_derived` and `retention/apply.rs::delete_one` follow the new key. Evidence: `crates/terminus-core/src/store/schema.rs:297-308,413-419`, `crates/terminus-core/src/reindex.rs:20-48,123-145,233-243`, `crates/terminus-core/src/derive.rs:152-170`, `crates/terminus-core/src/ingest/mod.rs:521-541`, `crates/terminus-core/src/observe/mechanical.rs:155-161`, `crates/terminus-core/src/retention/apply.rs:170-178`.

## Decisions

- D-01 (CI, #47): The tests get a new workflow file of their own, apart from `release.yml`, triggered on `push` and `pull_request`. It follows `release.yml`'s conventions: `permissions: contents: read`, actions pinned by SHA, `persist-credentials: false`, `shell: bash`, the pinned `RUST_VERSION` 1.97.1, and `--locked`. It reads no secret. Evidence: `.github/workflows/release.yml`, `.github/workflows/fast.yml`, `crates/terminus/tests/release_workflows.rs`.
- D-02 (CI, #47): The workflow runs on all four release runners: `ubuntu-24.04`, `ubuntu-24.04-arm`, `macos-15-intel` and `macos-15`. One Linux and one macOS runner was rejected, because 0.1.0's aarch64 install bug is the kind only those runners catch. The repo is public, so standard runner minutes cost nothing. Evidence: `.github/workflows/release.yml`, `.github/workflows/release-check.yml`.
- D-03 (CI, #47): The workflow installs or checks every tool the shell tests name, not only `dash` and `ssh-keygen`: `sha256sum` or `shasum`, `openssl` for `s_server -WWW`, `readlink`, `mktemp` and the rest of `install_script.rs`'s `TOOLS`. A missing tool fails the run before `cargo test` starts. Evidence: `crates/terminus/tests/install_script.rs:1-56,330-333,376-380`, `crates/terminus/tests/sign_release.rs:1-22`.
- D-04 (CI, #47): The timing-budget tests keep their budgets and run on the debug build, as they do locally. A budget that fails on a hosted runner is a finding this phase resolves with the owner's call, because the suite must pass in CI. Running CI with `--release` and loosening the spawn budgets on hosted runners were rejected. Evidence: `crates/terminus/tests/hook.rs:377-410,602`, `crates/terminus/tests/backfill.rs:44-47`, `crates/terminus/tests/lock_race.rs:21`, `crates/terminus/tests/corpus.rs:426`.
- D-05 (test gating, #44): `[[test]]` with `required-features = ["testkit"]` is declared for exactly the 27 files gated as a whole: 24 in `crates/terminus-core/Cargo.toml`, and `datamove`, `mcp` and `recall_cli` in `crates/terminus/Cargo.toml`. The four mixed files (`discover.rs`, `egress.rs`, `schema.rs`, `store_open.rs`) and `crates/terminus/tests/hook.rs`, which gates only its kill test, stay auto-discovered. Evidence: every file under `crates/*/tests/` classified by its `#![cfg(feature = "testkit")]` line, `crates/terminus/tests/hook.rs:16-22`, `crates/terminus/Cargo.toml`, `crates/terminus-core/Cargo.toml`.
- D-06 (test gating, #44): Cargo refuses a named `--test` whose required feature is off, but a package-wide `cargo test -p terminus-core` skips those targets without a word, and a bare `cargo test --workspace` turns `testkit` on through `crates/terminus`'s dev-dependency. So the notes that say to run with `--all-features` stay, and CI is what closes the gap. Measured 2026-10-15 in a scratch two-crate workspace with cargo 1.99.0. Evidence: `crates/terminus/Cargo.toml` (`[dev-dependencies] terminus-core = { features = ["testkit"] }`).
- D-07 (docs, #47): `README.md:50`, `README.md:149` and the per-PR list in `SECURITY.md:23` stop saying no workflow runs the tests, in the same change. Branch protection is not changed by this phase. Evidence: `README.md:50,149`, `SECURITY.md:23`, phase 9 D-09.
- D-08 (diverged read, #15): A flagged session opens its transcript once. One handle does the length check, reads `[0, watermark)` for the prefix comparison, then reads on to EOF for the tail. A session that is not flagged keeps today's path, seeking to the watermark and reading only the tail. Evidence: `crates/terminus-core/src/ingest/mod.rs:261-288,1013-1035,1042-1069`.
- D-09 (diverged read, #15): The one-handle read protects against the file being replaced between reads, by rename or by unlink and recreate. It does not protect against an in-place rewrite of the same inode during the read, and no identity or length re-check is added. Evidence: `crates/terminus-core/src/discover.rs:336-339`, issue #15.
- D-10 (diverged read, #15): The regression test uses the testkit open log: a diverged session's pass records exactly one open of its path. Timing a real swap between two reads is not attempted. Evidence: `crates/terminus-core/src/discover.rs:341-366`, `crates/terminus-core/tests/pass.rs:297`, `crates/terminus-core/tests/discover.rs:277-286`.
- D-11 (decisions table, #40): `compacted` and `dropped` are appended at the end of `decisions` in `CREATE_SQL`, and as a new `decisions` entry at the end of `BRING_FORWARD_COLUMNS`. A writable open adds them through `bring_forward`, with no `DERIVED_SCHEMA` involvement, and the drain's insert grows from 11 to 13 columns. Decisions drained before this build stay without the values, because their files are gone. Evidence: `crates/terminus-core/src/store/schema.rs:180-209,421-468`, `crates/terminus-core/src/store/open.rs:509-531`, `crates/terminus-core/src/feedback/mod.rs:182-208`, `crates/terminus-core/src/inject/decision.rs:148-152`.
- D-13 (replay, #40): For a decision with `compacted = 1`, `replay` re-scores through the compacted pool: the `compacted_ranked` window plus the stored `dropped` filter, as the live prompt arm does, so `--compacted-ranked` changes the result. Null and 0 rows replay through the ordinary window as today. The "What it cannot reconstruct" paragraph in `replay.rs` is rewritten. Evidence: `crates/terminus-core/src/feedback/replay.rs:28-34,218-260`, `crates/terminus/src/cmd/replay.rs:103,130-131`, `crates/terminus-core/src/inject/prompt.rs:379-420`.
- D-15 (stats and replay, #40): `stats` and `replay` still answer against a store that lacks the two new columns. They open read-only and never bring a store forward, so their queries check `missing_columns()` and treat the values as unknown. Evidence: `crates/terminus-core/src/store/open.rs:199-220,606-620`, `crates/terminus/src/cmd/read.rs:96-115`, `crates/terminus-core/tests/recall.rs:1670-1695`.
- D-16 (drain, #38): The drain deletes only the writers' own temp files, `decisions/.decision-*.tmp` and `injection/.inject-*.tmp`, once their mtime is older than a fixed age. The age is a constant in `terminus-core`, set with margin above a hook process's whole life (`DRAIN_DEADLINE` 500 ms, `INJECT_DEADLINE` 50 ms, plus startup), because the deadlines live in the binary crate and the drain lives in core. Each is checked with `symlink_metadata` to be a regular file. The sweep is housekeeping, not a failure, and puts nothing in `runs.error`. Evidence: `crates/terminus/src/cmd/hook.rs:95,108,252-285`, `crates/terminus-core/src/feedback/mod.rs:135-173`, `crates/terminus-core/src/ingest/pass.rs:272-281`, `crates/terminus-core/src/inject/decision.rs:357-372`, `crates/terminus-core/src/inject/state.rs:315-334`, `crates/terminus-core/src/store/open.rs:466-490`.
- D-17 (drain race): The race is fixed on the drain side. A zero-length `.json` younger than the D-16 age is a reservation still in flight: it is not inserted, not deleted and not reported, so the next pass reads the record renamed over it. An older one is deleted as malformed, as today, and a non-empty unparseable file is still deleted at once. Publishing with a no-clobber hard link from the writer was the alternative. Evidence: `crates/terminus-core/src/inject/decision.rs:294-325`, `crates/terminus-core/src/feedback/mod.rs:136-171`, `crates/terminus-core/tests/feedback.rs:560-603`.
- D-18 (comments, #38): Every comment the change makes false is corrected, not only the two the roadmap names: `cmd/hook.rs:236-237` (the abandoned thread writes state, and the prompt arm saves a decision), `state.rs:311-314` (state holds turn ids, not quoted prompt text), and `decision.rs:230-233`, which says the drain skips `.tmp` files. Evidence: `crates/terminus/src/cmd/hook.rs:232-237`, `crates/terminus-core/src/inject/state.rs:101-122,311-314`, `crates/terminus-core/src/inject/decision.rs:230-236`, `crates/terminus-core/src/inject/prompt.rs:213,463`.
- D-21 (boundaries, #17): A boundary sits at its own byte offset in the session stream. "Most recent boundary" is ordered by stream position, and the dropped set is the turns whose `stream_offset` comes before the boundary's. For boundaries backed by a turn this gives the same answer as today's `turn_seq` rule. Evidence: `crates/terminus-core/src/inject/compaction.rs:59-102,137-149`, `crates/terminus-core/src/store/schema.rs:256-270`, `crates/terminus-core/src/parse/record.rs:118`.
- D-22 (boundaries, #17): `DERIVED_SCHEMA` goes from 4 to 5, with its doc paragraph. The first ingest after the upgrade rebuilds every session's derived tables, and `compaction_owed` flags stuck on sessions whose boundary had no row clear on their next prompt. Evidence: `.planning/phases/12/CONTEXT.md` (Deferred), `crates/terminus-core/src/store/open.rs:30-50`, `crates/terminus-core/src/inject/state.rs:113-121`, `crates/terminus-core/src/inject/prompt.rs:542-561`.

## Acceptance criteria

- [ ] AC1: On every push and pull request, a workflow runs `cargo test --workspace --all-features --locked` on `ubuntu-24.04`, `ubuntu-24.04-arm`, `macos-15-intel` and `macos-15`. A failing test fails that run, and a missing shell-test tool fails it before `cargo test` starts. (human-verify: needs GitHub Actions)
- [ ] AC2: `cargo test -p terminus --test mcp`, and any other whole-file testkit test named without `--features testkit`, is refused by cargo with a message naming `testkit`. `cargo test --workspace --all-features` still runs every test file.
- [ ] AC3: A diverged session's ingest pass opens its transcript exactly once.
- [ ] AC4: On a store made before this change, an ingest adds `compacted` and `dropped` to `decisions`. A decision drained after a compaction is stored with `compacted` = 1 and its dropped turn ids. `terminus stats --json` counts compacted decisions apart from ordinary ones, `--compacted-ranked` changes `terminus replay`'s result for a compacted decision, and both commands still answer on a store without the new columns.
- [ ] AC5: A drain deletes `.decision-*.tmp` and `.inject-*.tmp` files older than the age limit and leaves younger ones. A zero-length `.json` younger than the limit survives the pass, and the record later renamed over it is inserted on the next pass. `hook.rs` no longer says the abandoned thread writes nothing, and `state.rs` no longer says state files hold prompt text.
- [ ] AC6: A `system`/`compact_boundary` record with no `uuid` or no `timestamp` gets a boundary row at its byte offset, the turns after it keep their ids, and the next prompt treats the turns before it as dropped. A store at `DERIVED_SCHEMA` 4 is rebuilt to 5 on first open, including one that holds evicted sessions.
- [ ] AC7: #47, #44, #15, #40, #38 and #17 are closed by the PR that fixes them, `README.md` and `SECURITY.md` no longer say no workflow runs the tests, and that PR's test run passes on all four runners. (human-verify: needs GitHub Actions)

## Flagged assumptions

- The GitHub `macos-15` and `macos-15-intel` images are assumed to need `dash` installed, and may lack an unprefixed `sha256sum` or an `openssl` that supports `s_server -WWW`; the suite has never run on macOS - Unclear, only a real run settles it; if wrong: every `install_script` and `sign_release` test fails on macOS with "{tool} is not on PATH".
- A debug-build hook on a hosted runner, macOS especially, is assumed able to meet `hook.rs`'s p99 under 10 ms over 100 spawns - Unclear, only a real run settles it; if wrong: D-04 applies and the failure is resolved in this phase with the owner's call.
- The D-16 age value is the planner's call, within the margin D-16 sets - Likely; if wrong: an age near `INJECT_DEADLINE` lets the drain delete a temp file whose write is still running, the writer's rename fails, and the record is lost.
- User-visible changes (the new `stats` keys, `replay` scoring compacted decisions, the drain sweep, the rebuild on first open) are assumed to get `[Unreleased]` entries in `CHANGELOG.md`, as phase 12 did - Likely; if wrong: the next release's notes miss them.
